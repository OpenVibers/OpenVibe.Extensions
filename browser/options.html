OpenVibe Coupons Helper

The helper works without connecting. Connecting lets it report whether a code worked, as you.

  1. On openvibe.coupons/connect-extension, sign in and create a token for this browser.
  2. Paste it here. It can only look up codes and report on them; it is not your OpenVibe sign-in.

Removes the token from this browser. Revoke it on openvibe.coupons as well.

Needed to report; the helper never asks for access to other sites.

What this extension can see

  • Only the hostname of the tab you are on, and only when you open the helper.
  • No page content, no full addresses, no cookies, no browsing history.
  • It talks to openvibe.coupons only.
